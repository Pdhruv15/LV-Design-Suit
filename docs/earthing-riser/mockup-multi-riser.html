Earth riser: two or more risers in one building (mockup)

Example: G+P4+8 tower. Riser EL-A runs the full height; riser EL-B serves the podium only (GF to P4). Same bar, test links and cable as the approved riser sheet, black and white.

Riser sheet: risers side by side

Each riser has its own floor earth bars (EB-EL-A-…, EB-EL-B-…), its own cable bar to bar, and its own cable from the LV room earth bar. A riser only has bars on the levels it serves.

How it is set up

  • Earthing settings → Risers: one row per riser per building: name, lowest and highest level served. Default: one riser EL-A, full height (as now).
  • Panel properties → Earth riser: which riser the panel's floor earth bar is on. Default: the first riser that serves the panel's level.
  • Tall buildings: the same choice as now (every level over sheets of 20, or typical floors grouped). Each sheet shows all risers for those levels.
