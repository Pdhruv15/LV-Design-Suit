What changes, and what stays

  1. Category tiles instead of 13 accordion rows. A 4 × 3 grid of icon tiles with a short label and count. One category is open at a time, so the list below never grows past one screen and nothing has to be scrolled past. The icons are the same SLD symbols the item becomes when dropped.
  2. Items as icon tiles, 3 per row. Each tile is the symbol plus a short name, with its size as a second line where it helps (45 kW, 22 kW). Feeder presets that carry a breaker + cable + load keep their two-line card, shown full width.
  3. Favourites and recently used as one pinned strip under the search, always visible, instead of two more collapsible groups.
  4. Click to place. Click a tile to arm it (highlighted, with a × qty badge you can step up or down), then click the busbar, feeder or canvas. Esc disarms. Drag still works exactly as now. This replaces the separate "Drop 1 at a time" field; shift-click adds 3 as a shortcut.
  5. Where-it-drops dots. Blue = busbar, green = feeder, amber = empty canvas, shown on every tile, with the same words in the hover card. This replaces the 3-line instruction paragraph, which moves into the hover card of each tile.
  6. Hover card with the full description that today is only a browser tooltip: name, size, what gets added, where it drops, and the click / shift-click hints.
  7. Collapsed rail (optional). When the side panel is hidden, a 46 px icon rail stays on the left with a flyout per category, like CAD tool palettes, so the canvas keeps its width.
  8. Unchanged: colours, fonts, panel width, search box, the tab strip, ★ on hover, edit / copy / delete actions on presets and components, the + / import / export tools for My presets and My components, and all drop behaviour on the SLD.
