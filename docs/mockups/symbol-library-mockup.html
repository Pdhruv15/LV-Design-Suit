LV Design Studio — proposed symbol library (IEC 60617)

Black-and-white, drawn from scratch on a 2.5 mm grid (no artwork copied from other libraries). IEC 60617 numbers to be re-checked against the IEC database at implementation.

One size for every symbol: each main symbol fits the same 28 × 32 box (dashed guide), with the line entering at the top and leaving at the bottom on the same axis. In-line accessories (CT, toroid, drawout marks) are a fixed 12 units wide. Labels always start at the same point on the right, in the same text size.
