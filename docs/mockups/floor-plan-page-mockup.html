  • Where: a Floor plan ribbon tab (after 3 Detailed design) with all the tools; the Floor plan page shows the drawing like the SLD canvas. The Floor plan button on Project and 1 Concept goes to this page. No pop-up windows.
  • Open plan loads the DWG / DXF into this canvas. The plan stays open while you move between pages; the project remembers it and reopens it next time.
  • Into the model at once, each one undo step: click inside / trace a room → room added; pick name → renamed; Add found rooms → all found rooms added or updated; link a route → that feeder's length updated (route + vertical + terminations + waste); tray run → tray route length and the feeder's trays updated; place board → its room, level and position updated. Rounded to two decimals.
  • Panel on the right: what is in the model now (Rooms · Cables · Trays · Boards), and what the plan has that is not added yet. Allowances (vertical, terminations, waste) on the Cables panel.
  • Kept: the drawing is never changed; links are kept in the project; Finder → Open with LV Design Studio opens the plan on this page.
