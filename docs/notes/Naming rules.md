# Naming rules

- Format: **type – level – number** → `SMDB-GF`, `SMDB-L1`, `DB-L2-02`
- Numbers are **incremental** and padded (01, 02 …); a new batch continues after existing panels.
- Emergency panels use their own prefixes: `EMDB`, `ESMDB`, `EDB`.
- Prefixes can be changed per project (Panels page → Naming tab).
- Renaming updates every reference (feeders, SLD, ties, arrows).
